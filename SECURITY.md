# Security and sensitive data

This project processes local image/archive files and launches configured local applications. Run it only with application paths and scripts you intend to execute. The helpers do not provide an image-upload service or a network control server.

For a vulnerability, use GitHub's **Report a vulnerability** option on the repository Security tab when available. If it is unavailable, open a minimal issue requesting a private reporting channel without posting exploit details, sensitive files or credentials. Do not attach real patient DICOM as a public reproduction.

Include a synthetic reproduction, the affected version and the observed impact. Reports are reviewed on a best-effort basis; there is no promised response SLA or clinical support service.

Ordinary geometry/segmentation bugs belong in a normal issue with synthetic data. Identifiable patient information, licenses, SSH keys, access tokens and private workstation addresses do not belong in issues or pull requests.
