# Changelog

## 1.0.0 — 2026-10-30

Initial public release of the research conversion workflow.

- Agent instructions and configurable local execution.
- DICOM, NIfTI, NRRD, segmentation and selected MRB intake.
- Raw-CT candidate segmentation and unlabeled-MRI review workspace.
- Gmsh tetrahedral meshes and explicit native-voxel option/fallback.
- Geometry-only INP and optional actual CAE import.
- Provenance, quality, status, failure and hash records.
- Synthetic regression tests, initial integration evidence and bilingual usage documentation.

This release does not establish universal automatic segmentation, a complete load-ready foot model, clinical validity or solve-time performance.
